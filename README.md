# FabriBond Plus Website

## About the Project

FabriBond Plus is a professional fabric repair solution website designed to showcase the product, explain its applications, provide step-by-step usage instructions, and allow customers to connect for product enquiries and orders.

The website provides a clean, modern, responsive, and user-friendly experience for both B2B and B2C customers.

---

## Features

- Modern and professional website design
- Fully responsive layout
- Mobile, tablet, laptop, and desktop support
- Product-focused Hero section
- FabriBond Plus product information
- Product features and applications
- Step-by-step "How to Use" section
- Customer reviews section
- B2B and B2C information
- Contact and enquiry form
- WhatsApp enquiry integration
- Instagram integration
- Product demonstration videos
- Sticky WhatsApp contact button
- Smooth scrolling navigation
- Interactive buttons and hover effects
- Product-focused animations
- Multilingual language selection
- English, Hindi, and Gujarati language support
- Language preference saved using browser LocalStorage

---

## Supported Languages

The website supports three languages:

- English
- हिंदी
- ગુજરાતી

English is the default language.

Users can select their preferred language from the language selection popup and change the language later from the navigation bar.

## Website Sections

### 1. Home

The Home section introduces FabriBond Plus with product information, key highlights, customer statistics, and a clear call-to-action.

### 2. About

Provides information about FabriBond Plus, its everyday applications, and important product information.

### 3. Features & Applications

Shows different applications and benefits of the fabric repair solution for individual and professional users.

### 4. Customer Reviews

Displays customer feedback through an interactive review section.

### 5. How to Use

Provides step-by-step instructions along with product demonstration videos.

### 6. Contact Us

Customers can submit their requirements through the enquiry form and connect directly through WhatsApp.

### 7. Footer

Includes business information, social media links, contact details, and website development information.
